# FileOrganizerCore — فایل‌های منتشرشوندهٔ سایت

این پوشه منبع انتشار GitHub Pages است؛ راهنمای فعلی و تاریخچهٔ ادغام‌شده در [راهنمای وب](../docs/WEB_GUIDE.md) قرار دارند.

- `index.html`: صفحهٔ اصلی
- `checkout.html`: پرداخت
- `config.js`: تنظیمات عمومی و لینک واقعی دانلود نصب‌کننده
- `privacy.html` / `terms.html`: حریم خصوصی و شرایط استفاده
- `assets/home-*.js`: منابع صفحهٔ اصلی؛ پس از تغییر با `node scripts/build-home.cjs` از ریشهٔ مخزن، runtime را بسازید.

کلید سرور پای و service-role هرگز در این پوشه قرار نمی‌گیرند. این پاک‌سازی شبکهٔ پرداخت را تغییر نمی‌دهد.
